## 一句话现状（2026-11-14）

P4 端全部功能已跑通：1080p 采集 → 网页推流 / SD 录像 / 双流日志 / UART 对接 STM32 / AI 规则决策。
**未完成的只有两件**：补光灯颜色闭环（要等 STM32 侧加 `light_r/g/b` 命令）、PC 侧 YOLO11 推理脚本。

## 三条最容易踩的坑（先记住这三条，能省几小时）

1. **UART 的 RX 不能接 GPIO38** —— 那是 console RXD，占了就失去串口输入。现在用 `TX=22 / RX=21`。
2. **SD 卡必须使能片内 LDO 通道 4** —— 否则 `sdmmc_init_ocr` 返回 `0x107`，换几套引脚都没用。
3. **AVI / CSV 必须 `fsync`** —— 只 `fflush` 不落盘，断电后文件大小是 0。
