## 二、电源域与地（共 4 个电源、2 种地）

| 编号 | 电源 | 供给 | 备注 |
|---|---|---|---|
| P1 | 36V 适配器 → 12V/20A 模块 | TEC×2、PTC、风扇×3、雾化器、继电器线圈 | **PGND 的源头** |
| P2 | 12V → 5V | STM32 逻辑、按键、传感器 | 纹波要小 |
| P3 | 5V（单独一路） | WS2812 灯环 16 颗 | 满白 960mA，**不要从 STM32 排针取** |
| P4 | USB（PC） | ESP32-P4 及其摄像头 | 也可以改由 12V→5V 供给 |

### 地

| 名称 | 范围 | 走什么电流 |
|---|---|---|
| **PGND**（功率地） | 12V 模块 OUT−、TEC、PTC、风扇、灯环 | 几安培 |
| **SGND**（信号地） | STM32、传感器、OLED、ESP32-P4 | 毫安级 |

**规则：SGND 与 PGND 只在 12V 模块 OUT− 处单点相连，其他地方不许再连。**

```
   12V 模块 OUT− ──┬── PGND（TEC/PTC/风扇/灯环）
                   └──[单点]── SGND（STM32 / 传感器 / P4）
```

## 五、两块板之间的连线（就 3 根）

| 从 | 到 | 说明 |
|---|---|---|
| P4 左列第 6 行 **GPIO21**（RX） | STM32 **PA2**（USART2 TX） | 交叉 |
| P4 右列第 6 行 **GPIO22**（TX） | STM32 **PA3**（USART2 RX） | 交叉 |
| P4 右列第 7 行 **GND** | STM32 **GND** | 必须 |

- 电平：两边都是 **3.3V**，直连，不需要电平转换
- 波特率：**115200 / 8N1 / 无流控**
- 三根线物理位置相邻（同一行 + 下行右侧），可做一根 3 芯短线束

## 六、接线规矩

```
① 接线 → 上电 → 断电 → 拆线        永不带电插拔
② 一块板同一时刻只留一个电源        不要 USB 和模块同时供电
③ SGND 与 PGND 只在 12V 模块 OUT− 单点相连
④ 跨板信号线串 1kΩ 电阻             防闩锁（已付出过一次代价）
⑤ 5V 大电流（灯环）单独走线         不从 STM32 排针取
⑥ 板间地线用短粗线（<15cm，≥24AWG）
```

## 七、核对清单（装机时逐条打勾）

### 电源
- [ ] 12V 模块输出实测 12.0~12.5V
- [ ] 12V→5V 输出实测 4.9~5.1V
- [ ] STM32 的 3.3V 引脚实测 3.28~3.32V
- [ ] SGND 与 PGND 只在 OUT− 处连通（其余不通）
- [ ] 灯环 5V 单独供电，满白电流 < 1A
- [ ] STM32 与 P4 各自只有一个电源接入

### 板间
- [ ] P4 GPIO21 ← STM32 PA2（万用表通断确认）
- [ ] P4 GPIO22 → STM32 PA3
- [ ] P4 GND ↔ STM32 GND 导通（0Ω）
- [ ] 三条线各串 1kΩ 或已确认无需

### 传感器
- [ ] 室内 SHT30 地址 0x44（ADDR 接 GND）
- [ ] 室外 SHT30 地址 0x45，接 PB8/PB9
- [ ] OLED 地址 0x3C 或 0x3D，与 SHT30 不冲突
- [ ] I2C 上拉电阻 4.7k（模块自带上拉则跳过）

### 执行器
- [ ] PB14/PB15 接的是**常闭**触点（万用表确认：断电时导通）
- [ ] PB13 → 雾化器继电器 → 并联面板按键（不是串在电源里）
- [ ] TEC 与 PTC 不会同时通电（互锁）
- [ ] 继电器模块 VCC 接 5V，GND 回 SGND

### 调试口
- [ ] ST-Link 只接 SWDIO / SWCLK / GND（3.3V 脚悬空）
- [ ] 板载 CH340 的 USB 只在断电状态下插拔

## 八、已知雷区

| 雷区 | 后果 | 原因 |
|---|---|---|
| 带电插拔 TTL / ST-Link | **MCU 闩锁，板子报废** | USB 插头接触瞬间的尖峰经信号线灌入引脚 |
| 外部 5V 和 USB 5V 同时接板子 | 两源互顶，电压异常 | 没有防反二极管 |
| P4 用 GPIO37/38 接外设 | 串口监视器失去输入 | 那是 console UART |
| 灯环从 STM32 排针取 5V | 排针/走线过热 | 满白 960mA |
| PB14/PB15 当普通高有效继电器用 | 风扇逻辑反了 | 接的是常闭触点 |
| 雾化器继电器保持高电平 | 面板按键被"按住"，雾化器行为不可控 | 只能发 200ms 脉冲 |
